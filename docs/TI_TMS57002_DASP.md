# Texas Instruments TMS57002 (DASP) 音频数字信号处理器参考

## 1. 概述

**Texas Instruments TMS57002**（常简称为 **DASP - Digital Audio Signal Processor**，芯片丝印如 *TMS57002DPHA*）是德州仪器于 1990 年代专门针对专业调音台、录音棚多效果器单元（如 Korg、LEM 音频设备）以及高端街机音频子系统（如太东 Taito Zoom 板卡）设计的高速、专用数字音频 DSP 芯片。

*(注意：请勿将本芯片与德州仪器现代 Hercules 汽车安全微控制器 TMS570 系列混淆，TMS57002 为完全独立的专用音频 DSP 架构)*。

---

## 2. 内部架构与计算管道

TMS57002 采用专门针对数字音频混响、多抽头延时、参数均衡以及 3D 环绕声算法优化的超高速微码执行架构：

### 2.1 存储体系
* **程序内存（PGM）**：内置 256 个 32 位宽指令存储空间，支持通过主机接口（Host Interface）在系统运行时动态上传。
* **系数存储区（CMEM）**：内置 256 个 24 位（或 32 位扩充）系数存储单元，用于存放滤波衰减因子、延时反馈比率与混音权重矩阵。
* **片内数据 RAM（DMEM0 与 DMEM1）**：
  * **DMEM0**：256 单元 × 24 位高速工作数据存储器。
  * **DMEM1**：32 单元 × 24 位辅助数据缓冲存储器。
* **外部数据 RAM（External Delay RAM）**：支持外挂 256 KB 至 1 MB 的高速外部静态或动态存储器，作为超长延时线（Delay Lines），为混响（Reverb Tail）提供历史样本保存空间。

### 2.2 数据格式与输入输出
* **音频采样格式**：支持 16 位与 24 位带符号 PCM 样本流（内部计算时扩展至 32 位与 48 位定点数）。
* **串行接口**：
  * **4 路串行音频输入（SI0, SI1, SI2, SI3）**：接收由 ZSG-2 等音频发生器输出的混响发送、合唱发送以及主左右声道信号。
  * **4 路串行音频输出（SO0, SO1, SO2, SO3）**：输出经 DSP 实时卷积处理后的反射声与环境音流。
* **输入缩放模式（ST0 SIM 位）**：
  * 当状态寄存器 `ST0` 的 `SIM` 位置位时，输入端口自动将 16 位样本左移 8 位缩放至 24 位内部格式。

## 3. 主机控制接口（Host Interface）与动态参数更新

TMS57002 作为从属协处理器，由外部控制 CPU（如松下 MN10200）通过专用的引脚与总线驱动：

### 3.1 PLOAD 与 CLOAD 控制线
* **`PLOAD`（Program Load）**：低电平有效。当主机拉低此线并依次通过 8 位数据口输入字节时，DSP 进入指令微码烧录模式。
* **`CLOAD`（Coefficient Load）**：低电平有效。当主机拉低此线时，DSP 顺序接收新的滤波器算法系数并存入 CMEM。

### 3.2 16 项参数更新队列（Update Queue）
在游戏实时运行过程中，主程序需要频繁调整混响房间尺寸（Room Size）、衰减时间（Decay）或回音增益，但若直接打断 DSP 运算会导致音频爆音。为此，TMS57002 硬件内置了一个深度为 16 层的 **参数更新队列（Coefficient Update FIFO）**：
* 主机 CPU 可以在 DSP 正常处理音频流的同时向队列压入更新值。
* DSP 在执行到对应系数读取地址的微码时，自动将队列中匹配地址的最新数值安全原子替换，从而实现完全平滑、无爆音的参数过渡。

## 4. VGM 扩展数据块 0x98（DSP 完整状态序列化）

在长达数分钟的游戏场景切换中，如果 VGM 播放器需要从头重放所有主 CPU 对 DSP 的微码上传和上万次参数修改，会导致 seek 与切歌极其缓慢。`libvgm` 实现了针对 TMS57002 的完整硬件快照镜像（Data Block 0x98）：

### 状态镜像结构（Version 1，Little-Endian 对齐）：
1. **控制与状态寄存器**：`version`, `st0`, `st1`, `sti`, `aacc`, `xoa`, `xba`, `xwr`, `xrd`, `txrd`, `creg`。
2. **算术累加器状态**：64 位有符号数 `macc`, `macc_read`, `macc_write`。
3. **流水线与程序计数器**：`pc`, `hpc`, `ca`, `id`, `ba0`, `ba1`, `rptc`, `rptc_next`, `sa`, `hidx`, `allow_update`, `update_head`, `update_tail`。
4. **更新队列与主机数据**：`host[4]`, `xm_adr`, 16 项更新值 `update[16]` 及其地址 `update_addr[16]`。
5. **片内存储映像**：
   * `pgm[256]`（程序内存，1024 字节）
   * `cmem[256]`（系数内存，1024 字节）
   * `dmem0[256]`（内部数据内存，1024 字节）
   * `dmem1[32]`（辅助数据内存，128 字节）
6. **外部延时 RAM 稀疏跨度（Sparse External Memory Spans）**：
   * 记录 `nspans` 个非零内存区块：每个区块包含 `{ u32 offset; u32 length; u8 data[length] }`，未覆盖区域自动置零。加载时可实现瞬间还原完整延时线尾音。
