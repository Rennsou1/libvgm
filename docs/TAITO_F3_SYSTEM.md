# Taito F3 System (Cybercore) 街机音频子系统架构

## 1. 平台概述

**Taito F3 System**（俗称 F3 基板，内部代号 *Cybercore*）是日本太东（Taito）株式会社于 1992 年推出的一款 32 位模块化街机主板系统。该主板采用了主板-卡带分离式设计，衍生出多款经典横版射击、动作与解谜街机大作，例如《Darius Gaiden》（大流士外传）、《RayForce》（断罪者）、《Bubble Symphony》（泡泡交响曲）、《Elevator Action Returns》（电梯大战归来）以及《Puzzle Bobble 2》（泡泡龙 2）。

除图形渲染能力出众外，F3 基板的音频处理架构在 1990 年代初期的街机硬件中处于顶尖水平，首次将专业级波表合成芯片与可编程混响 DSP 结合，创造了极具震撼力和空间临场感的音效表现。

## 3. 音频子系统内存映射与通信

音频 CPU（68000）独立于主 CPU 运行专属的声音驱动引擎（Sound Driver），其物理地址空间布局如下：

* **0x000000 - 0x01FFFF**：音频固件 ROM（包含声音驱动引擎、音符序列表与音效触发逻辑）。
* **0x140000 - 0x140FFF**：主 CPU 与 音频 CPU 双向通信命令/应答寄存器（Latch）。
* **0x200000 - 0x20001F**：ES5510 (ESP) 主机寄存器端口。
* **0x260000 - 0x26001F**：ES5505 (OTIS) 主机寄存器端口。
* **0x280000 - 0x280001**：ES5505 外部 Bank 切换控制端口（exbank control）。
* **0xC00000 - 0xC0FFFF**：音频工作 RAM（64 KB SRAM）。

### 主从握手协议（Handshake Protocol）
主 CPU 仅向音频子系统发送高层音效触发命令（如 `PLAY_BGM <song_id>` 或 `PLAY_SFX <sfx_id>`），音频 68000 接收到命令后自主分配 ES5505 发声通道，加载对应的波表样本、配置音量与包络参数，并向 ES5510 下发混响算法参数。

## 4. ES5505 与 ES5510 的信号流走线与混音拓扑

在 Taito F3 硬件上，ES5505 的 8 个物理输出通道并不是全部直接混合输出，而是与 ES5510 形成了灵活的干湿声处理拓扑：

1. **直接干声（Dry Path）**：
   * 通道 0 与 通道 1 作为直接立体声主干道（Direct Left/Right），经模拟增益网络直接输出到主 DAC。
2. **DSP 湿声处理通道（Wet / Reverb Path）**：
   * 通道 2 至 通道 7 作为特效发送通道（Aux/Send Bus），直接接入 ES5510 的串行数字输入端口（SER0 ~ SER2）。
   * ES5510 执行由 68000 下发的实时混响与合唱微码程序，计算出反射声与空间混响混音。
   * ES5510 最终将处理完毕的立体声信号通过输出端口（SER3 L/R，即输出通道 6/7）回送并叠加至最终的立体声总线上。
3. **数字音量调控**：
   * 街机机台的维护菜单（Test Mode）提供了软件数字音量调节功能，声音驱动程序会根据设置动态重算 ES5505 各通道输出增益。

## 5. 经典游戏应用案例

* **《RayForce》（断罪者 / 镭射风暴）**：Tamayo Kawamoto 编曲，大量利用 ES5505 的弦乐与合成打击乐样本，并通过 ES5510 营造了太空射击游戏标志性的宏大深空混响。
* **《Darius Gaiden》（大流士外传）**：Zuntata 乐队的殿堂级作品，广泛应用人声吟唱（如《Visionnerz》）与交响管弦乐波表，复杂的双向循环与低通滤波让有限的 ROM 空间实现了极具层次的音乐表现。
