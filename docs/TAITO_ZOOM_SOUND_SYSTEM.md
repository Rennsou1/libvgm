# Taito Zoom 音频系统（FX-1B / Wolf / G-NET / ZN-1 / ZN-2）架构参考

## 1. 架构概览

**Taito Zoom 音频系统（Taito Zoom Sound System）** 是日本太东株式会社（Taito）与其技术伙伴日本 Zoom 公司合作打造的一套高规格 3D 街机音频子系统架构。该系统最早见于 Taito FX-1B 基板，随后被深度集成在 Taito Wolf System、Taito G-NET、Sony ZN-1 与 ZN-2 街机硬件上。

该系统的核心设计哲学是将 **超多通道采样回放** 与 **广播级实时数字混响/三维环绕声 DSP** 完全硬件解耦，由一颗专属的高性能 RISC 微控制器进行音轨调度，创造了 1990 年代街机界最顶级的游戏原声表现。

## 3. 核心元器件职能分工

1. **松下 MN10200 / MN10208 微控制器**：
   * 负责接收主系统（如 PlayStation 架构的 R3000 CPU）发出的音效触发与 BGM 切换指令。
   * 维护 48 个通道的发声池分配，动态处理音符 Key-On / Key-Off、音量包络渐变以及截止频率调制。
   * 负责在每个关卡加载时，向 TMS57002 上传专属的混响算法微码（如小房间、大教堂、宇宙空间等不同声学场景）。
2. **ZOOM ZSG-2**：
   * 负责高精度样本的变调、插值、包络计算与两级滤波，输出 4 个基准声道的 16 位样本流。
3. **Texas Instruments TMS57002**：
   * 负责实时模拟空间声学反射与混响尾音，通过与 256KB 外部延时存储器的数据交换，实现极具临场感的立体声特效。

## 4. VGM 扩展命令 0xE4 规范

VGM 播放器针对 Taito Zoom 音频系统实现了专用指令 `0xE4`：

### 指令格式：
* **`0xE4 00 oo dd`**：向 ZSG-2 通道与控制寄存器写入数据（偏移为 `oo`，数据为 `dd`）。
* **`0xE4 01 00 dd`**：向 TMS57002 数据端口写入字节 `dd`（参数/微码传输）。
* **`0xE4 02 00 dd`**：向 TMS57002 控制引脚写入状态（Bit 0: PLOAD, Bit 1: CLOAD）。
* **`0xE4 03 00 00`**：执行 TMS57002 软复位。
* **`0xE4 04 00 00`**：执行 ZSG-2 芯片软复位。
* **`0xE4 06 cc gggg`**：配置音频板硬件混音增益（`cc` 为母线 ID，`gggg` 为 8.8 格式增益值）。
  * `0x00..0x03`：ZSG-2 输出到 DSP 输入增益
  * `0x10..0x13`：DSP 输出到左主声道增益
  * `0x14..0x17`：DSP 输出到右主声道增益
  * `0x20..0x23`：ZSG-2 旁路直通左声道增益
  * `0x24..0x27`：ZSG-2 旁路直通右声道增益
* **`0xE4 08 pp pp`**：执行 DSP 预运行（Pre-run），在静音状态下提前计算指定采样周期的混响算法，消除初始无声或切歌迟滞。

### 数据块支持：
* **`0x97`**：ZSG-2 样本 ROM 数据块（ROM 镜像上传）。
* **`0x98`**：TMS57002 DSP 完整内存快照数据块（微码、系数、通用寄存器及外部 RAM 稀疏延时线镜像）。
